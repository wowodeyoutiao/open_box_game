# 原服机制在当前游戏的实际使用范围

> 问题：原服（`nanoserver`）是多款游戏的公共基座，当前这款游戏到底用到了哪些机制？
> 结论：**只用到一小部分**。我上一轮"下一节点做 Buff 系统"的判断是错的。
> 核查时间：2026-10-27 14:15

## 一、三个决定性事实

### 1.1 玩家职业只有 3 个

`JobType` 枚举（`ProtoM/HttpM.cs`）：

```csharp
Warrior = 1,    // 战士
Mage = 2,       // 法师
Sacrifice = 3,  // 祭祀
```

建号 UI（`UICreatRole`）是 `int job = i + 1;`，只可能产生 1 / 2 / 3。

但 `role.json` 里有 7 个职业：

```text
job 1 / 2 / 3    1-150 级    ← 当前游戏在用
job 11 / 12 / 13 1-150 级    ← 旧玩法继承，当前建号入口选不到
job 21           1-150 级    ← 同上
```

`skill.json` 里 `SkillProfession` 也是 1/2/3/11/12/13/110 七套，
其中 11/12/13 是「1/2/3 + 10」的进阶职业，110 是特殊职业。

**结论：prof 11/12/13/110 的技能数据是死配置。**

### 1.2 玩家实际主动技能只有 10 个

prof 1/2/3 共 282 条技能数据，但骨架只有这些：

| 职业 | 普攻 | 技能 1 | 技能 2 | 技能 3 | 技能 4 |
| --- | --- | --- | --- | --- | --- |
| 战士 (1) | 普通攻击(1) | 月弧斩(2)<br>扇形 | 四方斩(3)<br>十字 | 破军斩(4)<br>长方形 | — |
| 法师 (2) | 普通攻击(14) | 魔法飞弹(15)<br>落点方框 | 星爆术(16)<br>落点方框 | 极光脉冲(17)<br>长方形 | — |
| 祭祀 (3) | 普通攻击(27) | 灵魂符咒(28)<br>落点方框 | 震地波(29)<br>长方形 | 群体治愈术(36)<br>自身方框 | — |

每个技能 30 级成长 + 进阶。

### 1.3 怪物只用普攻

`monster.json` 全 405 条怪物，`Skills` 字段只有两种值：

```text
999900      405 条   ← 怪物普攻（SkillID 9999）
1000000     1 条     ← 世界 boss
```

**所有剧情怪、精英怪、Boss 都只放普攻。**

## 二、机制使用矩阵

### ✅ 当前游戏确实在用（我实现的是对的）

| 机制 | 依据 |
| --- | --- |
| 扇形 / 十字 / 长方形 / 落点方框 / 自身方框 五种形状 | 10 个主动技能刚好覆盖全 5 类 |
| 伤害延迟 `DelayTime` | 玩家技能 Delay 600-700ms，怪物普攻 500ms |
| 切比雪夫距离 `max(|dx|,|dy|)` | `MaxDistance` 过滤，客户端 `getHurtDistance` 同口径 |
| 命中 / 闪避 | 怪物有 `HIT` / `DODGE`（BassProperty 7 / 6） |
| 暴击 + 暴击伤害 | `BaseValue.Crit` + `CRITICAL_DAMAGE_PERCENTAGE` |
| 5 层减伤 `DMT_*` | 装备/被动可带，怪物有 `PHYSICAL_DEFENSE` |
| CD 3/5/8/18 秒 + `SkillCooldownPush` | 月弧斩 3000 / 四方斩 5000 / 破军斩 8000 / 群体治愈 18000 |
| `Needaim` | 玩家技能 `Needaim = 1` |
| 技能 `SkillEffect` 属性加成 | 月弧斩 `[{13:500},{1:10}]` 等，全部有 |

### ❌ 当前游戏根本触发不到（白做但成本极低）

| 机制 | 为什么用不到 |
| --- | --- |
| 斩杀 `SkillID 57` | 挂在 prof 11（进阶战士），建号选不到 |
| 嘲讽 `SkillID 58` | 同上 |
| 护盾 `SkillID 51` | 同上 |
| 践踏 / 吸取 / 金身 / 重击 / 分身 | 同上 |
| boss 技能 59-85（怒气/卸甲/毁伤/恐惧/中毒/致盲/灭世/出血/破兵/回血/群防/重生/群攻/净化/群爆/回生/专注/免疫/强身/重甲/重伤/爆发/封锁/战意/护甲/猛攻/自愈） | 挂在 prof 12/13，选不到 |
| 特殊技能 500/501/600/601（千里冰封/剑开天门/时空凝结/魔法酸雨） | prof 110，选不到 |
| 多段攻击 `MulAttact` | 只在剑开天门(501) 上 |
| 怪物技能范围 | 怪物只有普攻 9999 |
| 护盾 / 免疫 / 伤害上限 buff | 玩家技能不产生，怪物不放技能 |

> 这些代码是几个 `switch case`，留着不影响任何东西。
> 后续做首领/塔/遗迹时如果启用带技能的 Boss，直接就能跑。

### ⚠️ 只有 1 个技能用到

```text
群体治愈术（祭祀 36）
  TriggerBuff = [8]
  Skillbuff   = [{15: 200}]     ← 15 = HEALTH_PERCENTAGE +2%
  SkillEffect = None            ← 没有伤害加成
  CoolDown    = 18000
  Radius      = 3（自身方框）
```

**10 个主动技能里，只有这 1 个带 Buff。**

## 三、所以 Buff 系统优先级要降

上一轮我建议"下一节点做 Buff 系统，因为技能 TriggerBuff 和 Attacked 护盾都依赖它"——**这个判断站不住**：

```text
玩家技能带 Buff 的：1 / 10
怪物放技能的：0
Attacked 的护盾/免疫：当前没有任何来源
```

Buff 系统做完，实际收益只有祭祀那一个治疗技能。
它不该排在 P1 的最前面。

---

## 四、真正该优先补的（数据驱动）

### ① 被动技能属性加成（高）

`skill.json` 里有一批 `ActiveorPassive = 2` 的被动技能，直接给属性：

```text
prof1 27000 [灵活]  SkillEffect [{6:20}]     → DODGE +20
prof1 28000 [坚韧]  SkillEffect [{9:30}]     → TOUGHNESS +30
prof1 29000 [厚泽]  SkillEffect [{15:500}]   → HEALTH_PERCENTAGE +5%
prof2 30000 [精准]  SkillEffect [{7:25}]     → HIT +25
prof3 33000 [精准]  SkillEffect [{7:25}]     → HIT +25
...（prof 11/12/13 还有 5001-5079 一大批）
```

现状：

- `SkillService.AutoLearn` **会把它们学进来**（`activeOrPassive == 2` 只是不装槽）；
- `RoleStatService` **完全没算它们**，代码注释里写着：

```text
/// 尚未接入命格、魂石、宠物、公会、VIP、被动技能和 buff。
```

**结果：玩家学了被动技能，但属性面板一点没加。** 这是所有职业都受影响的实际缺口。

### ② 技能进阶 `UpperlevelSetting.DamagePer`（中）

每个技能 30 级 + 进阶，进阶给的 `DamagePer` 直接加伤害。
当前完全没算，进阶了没效果。

### ③ 群体治愈术的治疗语义（中）

已修一半：补上了原服

```go
if len(skillCfg.Effect) == 0 && skillCfg.SType != SkillTypeNormal { power = 0 }
```

所以它现在不会打出伤害了。但**治疗本身还没实现**（要把 `HEALTH_PERCENTAGE` 加到目标身上）。
单机没有队友，实际只能奶自己。

### ④ Buff 系统（低）

只剩群体治愈术一个技能依赖，做最小版即可。

### ⑤ P2 首领 / 试炼塔 / 遗迹

这才是玩家真正感知得到的"新玩法"，比 Buff 更值。

## 五、本轮附带修掉的一个 bug

`ComputeSkillPower` 之前漏了原服这句：

```go
if len(skillCfg.Effect) == 0 && skillCfg.SType != constant.SkillTypeNormal {
    power = 0
}
```

导致**群体治愈术会走伤害公式去打人**。已补：

```csharp
bool hasEffect = skillCfg.SkillEffect != null && skillCfg.SkillEffect.Length > 0;
int sType = skillCfg.Skilltype;
if (!hasEffect && sType != 1)
    return 0;              // 无伤技能
```

`ApplyHit` 里 `power <= 0` 时只推送 0 伤害表现，不扣血。

验证：batchmode `battle` 10 条断言仍全 PASS。

## 六、修正后的路线

```text
P1-a  被动技能属性接入（RoleStatService 读 role.Skills 里的 ActiveorPassive=2）
P1-b  技能进阶 DamagePer
P1-c  群体治愈术治疗语义
P1-d  Buff 最小版（只服务群体治愈术，或直接跳过）
P2    首领 15 / 试炼塔 16 / 遗迹 17 复用 BattleMap 内核
P3    每日副本 / 守卫海岛独立状态机
```

**建议下一步做 P1-a 被动技能属性接入**：

1. 数据确定在用（每个职业都有）；
2. 改动集中在 `RoleStatService`，风险低；
3. 立刻影响战力/命中/闪避/韧性，玩家能感知；
4. 不做的话，玩家学了被动技能等于白学。

---

## 七、一句话总结

> 原服是基座，当前游戏只用了「三职业 × 四技能 × 五种形状 + 普攻怪」这一小块。
> 形状枚举、延迟生效、命中闪避、减伤这些**用到了**；
> 斩杀/嘲讽/护盾/boss 技能**没用到**，但留着不碍事；
> 真正欠的是**被动技能属性没算进面板**。
