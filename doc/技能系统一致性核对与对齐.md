## 一、原服技能链路（完整）

```text
Client  C2S_Attack { SkillId, TargetUids, Location, Direction }
  ↓
Player.attack(targets, skillId, location, direction)
  1. getSkillex(skillId)              技能必须已学习，否则失败
  2. GetSkillCfg(skillId)             读配置
  3. skillCfg.CoolDown > 0 && now < skill.Cooldown   → 拒绝
  4. GetRoomCfg(p.desk.cfgID)         房间配置必须存在
  5. Needaim == 0 → targets 清空
     Needaim != 0 && len(targets) == 0 → 拒绝
     被嘲讽时只能打嘲讽者
  6. direction 落在 [UP, UP_LEFT] 时写回 p.direction
  7. Radius = skillCfg.Radius + 进阶 Distance
  8. 按 skillCfg.SkillID 算攻击格子：
        HALF_MOON(2)           getSectorCells  扇形
        FOUR_SIDES(3)          getLineCells ×4 十字
        MAGIC_MISSILE(15) /
        STELLAR_BURST(16) /
        SOUL_TALISMAN(28)      getSquareCells(落点)
        BREAK_ARMY(4) /
        AURORA_PULSE(17) /
        EARTHQUAKE_WAVE(29)    getLineCells 长方形
        FreezeTime/TimeSpaceLock/Duel/RepelFoe/MassHeal/
        DivineStrength/ArcaneMastery/BlessingOfCourage/
        NetherSpell/DivineBattleArmor/Taunt/Stomp/
        Bleeding/Wreck/Apocalypse  getSquareCells(自己)
  9. 把 attackCells 里的对象并入 targets（去重 + CanAttackTarget + skillCfg.Object 过滤）
 10. 对每个 target：
        - 跳过自己 / 非法类型 / 房间类型不允许的
        - skillCfg.MaxDistance > 0 && maputil.Distance(玩家, 目标) > MaxDistance → 跳过
        - caster.target = t; caster.direction = 朝向目标
        - time.AfterFunc(skillCfg.DelayTime) → chDelayAttack ← DelayAction{Target: t}
 11. caster.SkillBuffTrigger(skill)      技能触发 buff
 12. skill.Cooldown = now + CoolDown - 500   并推 SkillCooldownPush
 13. Broadcast AttackPush{AttackerId, TargetUids(全部), SkillId, Location, Direction}
  ↓
Desk 主循环消费 chDelayAttack
  ↓
Player.delayAttack(target, skillId)
  1. CanAttackTarget / 技能必须已学 / GetSkillCfg
  2. 命中-闪避：hit < dodge && rand(dodge) > hit → Dodged()，直接 return（伤害 0）
  3. basePower = 攻击属性
     power = basePower + Σ skillCfg.Effect 加成
     （PHYSICAL/MAGIC_ATTACK 直接加；*_PERCENTAGE / PVE_DAMAGE_PERCENTAGE 按 BaseRate=10000 折算）
  4. 进阶加成 damage_percentage_increase（UpperlevelSetting.DamagePer）
  5. 暴击：critRate = (crit - toughness) * BaseValue.Crit.K + PreValue
     暴击时 damage_percentage_increase += CRITICAL_DAMAGE_PERCENTAGE
  6. power -= 目标防御（按攻击属性取物理/魔法防御）
  7. power += power * damage_percentage_increase / 10000
  8. 最终增伤：PVE/PVP_DAMAGE_PERCENTAGE、DMT_FINAL_INCREASE_* → 再加一轮
  9. power <= 0 → rand(2)+1
     len(Effect) == 0 && SType != Normal → power = 0
 10. 吸血：power * SUCKING_BLOOD_PERCENTAGE / 10000 + power * SpecialEffect.DamTransfer / 10000
 11. target.Attacked(p, skillId, AdvancedLevel, power, true)
  ↓
MapObject.Attacked
  1. 技能配置必须存在
  2. 斩杀：skillId/100 == SkillTypeExecute(57)
     且 currentHP/maxHP <= SpecialEffect.Slay/10000 → 直接清空 HP
  3. 暴击率判定 → damage = power * (1 + CRITICAL_DAMAGE_PERCENTAGE/10000)
  4. 减伤链：
        damage -= DMT_FINAL_REDUCE_FIXED
        攻击方是怪 → damage -= DMT_REDUCE_FIXED_MONSTER
                     damage -= damage * DMT_REDUCE_PERCENTAGE_MONSTER / 10000
        否则       → damage -= DMT_REDUCE_FIXED_PLAYER
                     damage -= damage * DMT_REDUCE_PERCENTAGE_PLAYER / 10000
        damage -= damage * DMT_FINAL_REDUCE_PERCENTAGE / 10000
        damage = max(damage, rand(2)+1)
  5. 护盾 buff 吸收 / 神圣天赋伤害上限 / 免疫 buff
  6. changeHp(-finalDamage)
  7. 怪物被玩家打时 o.target = attacker（这就是被动仇恨来源）
  8. 反伤
  ↓
ObjectHpChangePush / ObjectDiePush 广播
```

## 三、本轮已对齐（14 项里做了 10 项）

### 3.1 伤害延迟生效（#1）

新增 `BattleService.PendingHit` + `BattleRuntime.PendingHits`，等价原服 `chDelayAttack`：

```text
Attack() → 写 PendingHits{AtMs: now + skillCfg.Delay}
         → Tick 里 ResolvePendingHits 到点结算
```

玩家和怪物走同一条路径（原服 `MonsterInfo.attack` 也是 `time.AfterFunc(DelayTime)`）。

**这一条直接改变观感**：技能动作和特效先出，伤害后落地。

### 3.2 技能作用范围（#2）

新增 `InSkillArea`，按原服 `skillCfg.SkillID` 分形状：

```text
HALF_MOON(2)      扇形      方向偏差 <= radius 且距离 <= radius
FOUR_SIDES(3)     十字      四向直线
BREAK_ARMY(4)/AURORA_PULSE(17)/EARTHQUAKE_WAVE(29)  长方形  正前方
MAGIC_MISSILE(15)/STELLAR_BURST(16)/SOUL_TALISMAN(28)  落点方框
FreezeTime/TimeSpaceLock/Duel/RepelFoe/MassHeal/DivineStrength/
ArcaneMastery/BlessingOfCourage/NetherSpell/DivineBattleArmor/
Taunt/Stomp/Bleeding/Wreck/Apocalypse  自身方框
default（普攻/怪物普攻）  只打目标
```

> 原服是枚举格子（`getSquareCells` / `getSectorCells` / `getLineCells`），
> 单机没有服务端格子表，这里用等价几何判定近似。形状语义一致，边界格子可能有 1 格误差。

### 3.3 切比雪夫距离（#3）

```csharp
GridDistance = max(|dx|, |dy|)
```

替换所有技能距离 / 索敌判定。斜向 3 格现在算 3，不再算 4.24。

### 3.4 AttackPush 带全部目标（#4）

```text
LocalPusher.PushBattleAttackNow(new AttackPush { TargetUids = 全部 })
```

### 3.5 命中/闪避（#5）

```text
hit < dodge && rand(dodge) > hit → 推 ObjectHpChangePush{Miss = true, ChangeHp = 0}
```

### 3.6 减伤链（#6）

`ApplyDamageReduction` 逐层照抄：

```text
-= DMT_FINAL_REDUCE_FIXED
怪打你 → -= DMT_REDUCE_FIXED_MONSTER，-= damage * DMT_REDUCE_PERCENTAGE_MONSTER / 10000
你打怪 → -= DMT_REDUCE_FIXED_PLAYER， -= damage * DMT_REDUCE_PERCENTAGE_PLAYER / 10000
-= damage * DMT_FINAL_REDUCE_PERCENTAGE / 10000
damage = max(damage, 1)
```

`BattleUnit` 同步补了 6 个 `Dmt*` 字段，玩家从 `RoleStatSnapshot` 读。

### 3.7 斩杀（#7）

```text
skillCfg.SkillID == 57 && target.Hp / target.MaxHp <= SpecialEffect.Slay / 10000
→ 直接清空 HP
```

`CFGItem_Skill` 补了 `SpecialEffect` 字段（`Slay / DamTransfer / MulAttact` 等）。

### 3.8 冷却提前量 + 推送（#8 #9）

```text
_skillReadyAt[skillId] = now + CoolDown - 500
LocalPusher.PushSkillCooldownNow(new SkillCooldownPush { CfgId, Delay })
```

`LocalPusher.PushSkillCooldownNow` 新增，客户端 `Sever_SkillCooldownPush` 会写 `SkillM` 并刷 UI。

### 3.9 Needaim == 0（#10）

无目标技能不再直接报"没有攻击目标"，而是按施法方向算范围。

### 3.10 朝向计算（顺带）

`DirectionFromPoint` 改为原服 `maputil.DirectionFromPointF` 语义：**不比较绝对值大小**，
只要 X/Y 有差异就返回对角方向。

## 四、本轮踩到的 ILRuntime 坑（重要）

`BattleUnit player = _runtime.Player;` 这种**局部变量持有对象后读它的 enum 字段**，
在 ILRuntime 下会抛 `InvalidCastException: Specified cast is not valid`：

```csharp
BattleUnit player = _runtime.Player;
Direction castDir = player.Direction;     // ← 这里炸
```

但直接链式访问没问题：

```csharp
Direction castDir = _runtime.Player.Direction;   // ← OK
```

另外 `(double)skillCfg.Radius`（decimal → double）也会炸，必须用 `(int)skillCfg.Radius`。

**以后写热更代码注意**：

```text
1. 不要在局部变量上读 pb 枚举字段，直接链式访问
2. decimal 只转 int / long，不要转 double
```

## 七、后续方向建议

> **2026-10-27 14:15 修正**：原来这里建议「下一节点做 Buff 系统」，核对当前游戏
> 实际用到的机制后**这个判断不成立**。详见 `原服机制在当前游戏的实际范围.md`。
>
> 玩家 10 个主动技能里只有「群体治愈术」1 个带 Buff，怪物完全不放技能，
> `Attacked` 的护盾/免疫当前没有任何来源。Buff 应降级。
>
> 真正该先做的是 **被动技能属性接入**：`RoleStatService` 目前完全没算
> `ActiveorPassive = 2` 的被动技能，玩家学了等于白学。

### 原建议（已降级）：Buff 系统

理由：

1. 它是**唯一挡在"技能完整"前面的整块**——技能 `TriggerBuff` 和 `Attacked` 的护盾/免疫都依赖它；
2. 配置齐全：`buffeffect.json` + skill 的 `TriggerBuff` / `Skillbuff` / `Buffround`；
3. 协议齐全：`AddBuffPush` / `RemoveBuffPush`，客户端 `RoleM.AddBuffInfo` 已存在；
4. 做完之后 `Attacked` 的三层防护才能补齐，战斗才真正闭环。

范围建议（最小可用）：

```text
属性类 Buff（加攻/加防/加移速）   ← 复用 RoleStatService 的属性叠加
伤害类 Buff（持续掉血/中毒）       ← 需要 tick 结算
控制类 Buff（嘲讽/眩晕）           ← 只做嘲讽（影响目标选择，已有 hooks）
护盾 Buff（BuffShield）            ← Attacked 要用
减伤 Buff（复用 Dmt* 字段）
```

暂不做：

```text
圣物 / 天赋 / 元素克制 / 反伤
```
